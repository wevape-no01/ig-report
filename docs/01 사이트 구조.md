# 01 사이트 구조

상위: [[위베이프 SNS 리포트]]

## 메뉴 구성

맨 위 가로줄에서 **인스타그램 / 스레드**를 고르고, 왼쪽 세로줄에서 세부 페이지를 고릅니다.
오른쪽 위에는 외부 링크 버튼 **발행 관리**와 알림 종이 있습니다.

```
인스타그램 ─┬ 일일 리포트      index.html
            ├ 주간 리포트      weekly.html
            │   └ 지난 리포트  weekly-past.html
            └ 콘텐츠 분석      analysis.html
                └ 세부 분석    analysis-detail.html

스레드     ─┬ 일일 리포트      threads.html
            ├ 주간 리포트      threads-weekly.html
            │   └ 지난 리포트  threads-weekly-past.html
            └ 콘텐츠 분석      threads-analysis.html
                └ 세부 분석    threads-detail.html
```

하위 메뉴(지난 리포트 / 세부 분석)는 그 부모를 눌렀을 때만 펼쳐집니다.
폰·태블릿에서는 상위 메뉴 세 개가 첫 줄에 남고 하위 메뉴가 아랫줄에 따로 나옵니다.

## 각 페이지가 답하는 질문

| 페이지 | 답하는 질문 |
|---|---|
| 일일 리포트 | 어제 무슨 일이 있었나 |
| 주간 리포트 | 지난주보다 나아졌나 |
| 지난 리포트 | 예전 주차는 어땠나 |
| 콘텐츠 분석 | 어떤 소재가 잘 먹히나 |
| 세부 분석 | 왜 그런지 더 파고들기 |

## 일일 리포트 구성

인스타그램은 KPI 4칸(팔로워·게시물·오늘 도달·최근 게시물 도달) → 조회수 그래프 →
신규 팔로워 유입 → 팔로워 수 추이 → 최근 게시물 표 순서입니다.

스레드는 KPI 3칸(팔로워·글·최근 한 달 조회수) → 조회수 → 신규 팔로워 유입 →
팔로워 수 추이 → 최근 글 순서입니다. 누적 반응은 [[03 지표 정의]]의 이유로
2026-08-20에 세부 분석 쪽으로 옮겼습니다.

## 디자인 규칙

> [!danger] UI 고정 규칙 — 지시가 없으면 바꾸지 않는다
> 칸 사이 간격, 글꼴 크기, 카드 위치는 **사용자가 명시적으로 지시할 때만** 바꾼다.
> 다른 기능을 추가하거나 고칠 때 곁다리로 조정하지 않는다.
> 인스타그램과 스레드는 **같은 값**을 써야 하고, 플랫폼을 오갈 때 화면이 움직이면 안 된다.
>
> 값은 `layout.py` 의 `COMPONENT_CSS` 한 곳에만 둔다. 각 `build_*.py` 는 그 페이지에만
> 있는 것(예: 계정 탭, 샘플 배너)만 더한다. 같은 규칙을 두 파일에 복사하면
> 시간이 지나며 슬금슬금 달라진다 — 실제로 그랬다.
>
> 고친 뒤에는 두 페이지의 계산된 값을 재서 **전부 같은지 확인**한다.
> 기준: 첫 콘텐츠 y = 221px, 본문 폭 = 1265px, 글꼴 1종류, 섹션 간격 20px.


색은 크림 배경 `#F4F1E8`, 검정 메뉴 `#1A1A1A`, 포인트 노랑 `#FFC800`을 씁니다.
카드는 항상 흰색입니다.

글자 크기는 네 단계로만 씁니다.

| 단계 | 크기 | 예 |
|---|---|---|
| 페이지 제목 | 24px | 일일 리포트 |
| 계정·카드 제목 | 20px | 위베이프, @wevape.no01 |
| 섹션 제목 | 18px | 조회수, 핵심 지표 |
| 본문 | 14px | 설명 문장 |
| 보조 설명 | 11~13px | 작은 회색 글씨 |

그래프는 기본을 연한 베이지 `#D9D2C2`로 두고 **가장 큰 값 하나만** 칠합니다.
증감은 오르면 초록 `#1F8A45`, 내리면 빨강 `#C1392B`입니다.

| 자리 | 색 |
|---|---|
| 막대 기본 | `#D9D2C2` |
| 막대 강조 (가장 큰 값 하나) | `#FFCE33` |
| 팔로워 구성 막대 강조 | `#FFCE33` |
| 추이 선 | `#E8C24A` |
| 선 아래 면 | `rgba(255,222,122,.16)` |
| 메뉴·섹션 점·인사이트 띠 | `#FFC800` (그래프보다 진함, 그대로 유지) |

**축 표기** — 팔로워 수 추이는 가로축 오른쪽 끝에 `(월/일)` `(주 시작일)` `(월)` 중
보기에 맞는 단위가 붙고, 세로축은 왼쪽 위에 `(명)`이 한 번만 붙습니다.
세로축 눈금값은 716·718·720·722처럼 딱 떨어지는 숫자로 자동 계산됩니다.

## 파일 목록

`layout.py`가 모든 페이지의 껍데기(메뉴·색·글꼴·알림)를 담당하고,
각 `build_*.py`가 본문만 만듭니다. **색이나 글꼴을 고칠 때는 layout.py 한 곳만 고칩니다.**

| 파일 | 역할 |
|---|---|
| layout.py | 공용 껍데기 (메뉴·색·글꼴·알림) |
| instagram_api.py | 인스타 데이터 수집 |
| threads_api.py | 스레드 데이터 수집 |
| build_dashboard.py | 인스타 일일 리포트 |
| build_analysis.py | 인스타 콘텐츠·세부 분석 |
| build_threads.py | 스레드 일일 리포트 |
| build_threads_analysis.py | 스레드 콘텐츠·세부 분석 |
| build_weekly.py | 주간·지난 리포트 4개 |
| weekly.py | 주간 계산 로직 |
| weekly_issue.py | 월요일 주간 리포트 이슈 발행 |
| notice.py | 사이트 알림 기록 |
| fail_issue.py | 수집 실패 이슈 |
| rebuild.py | 최신 데이터 받아 페이지 재생성 (화면 수정할 때 이것만 실행) |
