# 04 알 수 없는 것들

상위: [[위베이프 SNS 리포트]]

여기 적힌 건 "아직 안 만든 기능"이 아니라 **Meta가 데이터를 주지 않아서 만들 수 없는 것**입니다.
나중에 같은 걸 또 검토하지 않으려고 남깁니다.

## 해시태그별 성과

어느 해시태그를 타고 들어왔는지 **API가 알려주지 않습니다.** 게시물마다 "몇 명에게 닿았다"는
총량만 옵니다. 해시태그 검색 API는 남의 인기 게시물을 훑는 용도이고,
내 게시물이 그 태그에서 몇 번 노출됐는지는 주지 않습니다.

우회 방법도 없습니다. 같은 소재를 태그만 바꿔 여러 번 올려 비교하는 방법이 있지만,
같은 날 같은 시간대가 아니면 조건이 달라져 비교가 성립하지 않습니다.

## 경쟁 계정 동향

남의 계정 인사이트는 **본인 계정 권한으로 볼 수 없습니다.** 공개적으로 보이는 건
팔로워 수와 게시물 수, 그리고 겉으로 드러나는 좋아요·댓글 정도입니다.
도달·저장·공유 같은 실제 성과 지표는 계정 주인만 봅니다.

Business Discovery API가 있긴 하지만 팔로워 수·게시물 수·좋아요·댓글 수준이고,
앱 심사를 받아야 하며 우리 앱은 개발 모드라 지금은 쓸 수 없습니다.

## 스레드 기간별 반응 수

**확인된 사실입니다.** 스레드가 계정 단위로 주는 일별 좋아요·답글·리포스트·인용이
36일치 기록 **전부 0**으로 옵니다. API 제약입니다.

그래서 "최근 30일 반응"이나 "이번 주 반응"을 만들 수 없습니다.
주간 리포트의 스레드 반응 숫자도 실제로는 주별로 변하지 않습니다.
6주치를 뽑아 보면 반응률 16.70%, 좋아요 1,769건이 여섯 주 내내 같습니다.

주간 리포트에서 **스레드는 조회수만 주별로 진짜 변합니다.**

반응을 볼 수 있는 유일한 경로는 게시물별 값을 전부 더하는 것이고, 그게 누적 반응입니다.

## 스레드에 없는 것

- 도달(reach) 자체가 없음 → 조회수만
- 게시물별 팔로우 수(follows)가 없음 → 어느 글이 팔로워를 데려왔는지 알 수 없음
- 답글의 답글은 집계되지 않음
- 리포스트로 올라간 글은 인사이트가 비어 분석에서 빠짐

## 인스타 분석에서 빠지는 글

도달·조회·저장 같은 인사이트는 **계정을 프로페셔널로 바꾼 뒤 올린 게시물에만** 있습니다.
그 이전 글은 분석에서 제외됩니다. 현재 @wevape.no01은 240개 중 142개가 분석 가능합니다.

또 오래된 게시물은 인스타가 도달을 적게 집계해 반응률이 비정상적으로 튑니다.
그래서 최근 24개월만 봅니다.

## 표본이 적을 때

표본이 5개 미만인 항목에는 화면에 경고를 붙여 뒀습니다. 우연일 가능성이 높으니
판단 근거로 쓰지 마세요. @wevape_japan은 팔로워 4명이라 비율 지표 대부분이 의미 없습니다.
