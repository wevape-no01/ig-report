# 06 문제 해결 기록

상위: [[위베이프 SNS 리포트]]

같은 고장을 두 번 겪지 않으려고 남깁니다.

## "N일째 데이터가 갱신되지 않았습니다" 빨간 띠

**증상** 2026-08-20에 "5일째 갱신 안 됨" 경고.
**원인** 수집은 매일 정상이었습니다(8/15~8/19 스케줄 실행 5번 모두 성공).
그날 화면 디자인을 고치면서 **8월 15일자 옛 데이터로 만든 HTML을 덮어썼던 것**이 원인이었습니다.
**교훈** 화면만 고칠 때도 반드시 저장소의 최신 JSON을 먼저 받아서 HTML을 만들어야 합니다.
**확인법** 저장소의 `report_data.json` 안 `generated_at`을 보면 실제 수집 시각이 나옵니다.
이게 최신인데 화면만 과거면 HTML 문제입니다.

> [!warning] 같은 사고가 2026-08-21에 또 났습니다
> 그래프 색을 고치면서 8월 19일자 데이터로 만든 페이지를 다시 덮어썼습니다.
> "다음부터 조심하겠다"는 약속으로는 막히지 않는다는 게 확인됐습니다.
> 그래서 절차를 사람 기억이 아니라 **스크립트**로 옮겼습니다 → 아래 [[#rebuild.py]]

## rebuild.py

화면만 고칠 때는 `build_*.py`를 직접 돌리지 말고 이것을 씁니다.

```
python3 rebuild.py
```

하는 일은 세 가지입니다. 저장소에서 최신 JSON 7개를 먼저 받고, 페이지 10개를 다시 만들고,
만들어진 페이지가 정말 그 최신 데이터를 쓰는지 검사합니다.
데이터가 36시간보다 오래됐으면 **거기서 멈춥니다.** 사이트에 빨간 띠가 뜨는 조건과 같은 기준입니다.
Meta API는 한 번도 호출하지 않으므로 계정 차단 위험이 없습니다.

내려받기가 하나라도 실패하면 옛 데이터로 페이지를 만들지 않고 중단합니다.

## Meta 개발자 계정 차단 (2회)

**원인** 짧은 시간에 API 요청을 몰아 보냄.
**대책** 요청 간격 0.4초, 실행당 신규 인사이트 80개 제한, 워크플로 반복 실행 금지.
[[02 자동 갱신 구조]] 참고.

## 스레드 반응이 전부 0으로 보임

**원인** 계정 단위 합계 API가 0을 돌려줌.
**해결** 게시물별 인사이트를 더해서 채우도록 보완. 실제로는 4,835건이 있었습니다.
이 API 제약 자체는 [[04 알 수 없는 것들]]에 정리했습니다.

## 페이지를 옮길 때마다 화면이 좌우로 흔들림

**원인** 내용이 긴 페이지는 세로 스크롤바가 생기고 짧은 페이지는 안 생겨서,
화면 폭이 15px씩 달라졌습니다. 지난 리포트·스레드 주간·스레드 지난 리포트가 짧은 쪽이었습니다.
**해결** 스크롤바 자리를 항상 비워 두도록 지정. 모든 페이지 본문 폭이 1265px로 같아졌습니다.

## 페이지마다 글꼴이 다름

**원인** 각 `build_*.py`가 글꼴을 따로 지정하고 있었고 두 종류가 섞여 있었습니다.
**해결** 페이지별 글꼴 지정을 전부 삭제하고 `layout.py` 한 곳에서만 정하도록 변경.

## 카드 배경이 페이지 배경과 같아 보임

**원인** 콘텐츠 분석 계열 4개 페이지의 카드에 배경색 지정이 빠져 있었습니다.
인스타 콘텐츠 분석은 페이지 배경까지 흰색이라 더 심했습니다.
**해결** 카드 배경 흰색, 페이지 배경 크림색으로 통일.

## 알림 "열어보기"를 눌러도 읽음이 안 됨

**원인** 팝업의 "읽음" 버튼에만 읽음 처리가 붙어 있고 "열어보기" 링크에는 없었습니다.
**해결** 링크에도 읽음 처리 추가. 더해서 팝업이 페이지마다 다시 뜨던 문제와
오래된 알림이 계속 뜨던 문제도 함께 고쳤습니다. [[05 알림 시스템]] 참고.

## 폰에서 화면이 좌우로 밀림

**원인** 최근 게시물 표가 화면보다 넓어 페이지 전체를 밀어냄.
**해결** 표 안에서만 옆으로 넘겨 보도록 변경.

## GitHub Pages는 비밀번호를 걸 수 없음

**사실** 저장소 접근 제어 기능은 Enterprise Cloud 요금제에서만 됩니다.
무료·Pro 요금제의 Pages 사이트는 **항상 공개**입니다.
자바스크립트로 비밀번호 입력창을 만드는 건 보안이 아닙니다.
저장소가 공개라 소스에서 그냥 읽힙니다. 대안은 [[08 앞으로 할 일]].
