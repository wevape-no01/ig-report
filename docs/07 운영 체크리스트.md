# 07 운영 체크리스트

상위: [[위베이프 SNS 리포트]]

## 매일 (1분)

- [ ] 사이트를 열어 **빨간 띠가 없는지** 확인. 있으면 [[06 문제 해결 기록]]의 첫 항목
- [ ] 일일 리포트에서 **신규 팔로워 유입** 숫자 확인 (초록이면 증가, 빨강이면 감소)
- [ ] **어디까지 퍼졌나**에서 비팔로워 비중 확인. 낮으면 늘 보던 사람만 보고 있다는 뜻

## 매주 월요일 (5분)

- [ ] 폰으로 온 **주간 리포트 이슈** 확인
- [ ] 주간 리포트에서 신규 팔로워·도달·조회수가 전주 대비 어떤지
- [ ] 콘텐츠 분석의 **오늘의 인사이트** 세 문장 읽기. 다음 주 소재 방향 정하기

## 매달 (10분)

- [ ] 콘텐츠 분석 → 세부 분석에서 **유형별 노출**과 **게시 시각별 노출** 확인
- [ ] 스레드는 해시태그 없이 쓴 글이 잘 되는지 재확인 (지금까지는 그랬음)

## 이상이 생겼을 때

**빨간 띠가 떴다** → 저장소 Actions 탭에서 최근 실행이 성공했는지 본다.
성공했는데 화면이 과거면 HTML 문제, 실패했으면 로그의 실패한 단계를 읽는다.

**수집 실패 이슈가 왔다** → 이슈 안에 실행 링크가 있다. 로그에서 `code 190`이 보이면
토큰 문제이거나 Meta 계정 확인 요청이다. Meta 개발자 페이지를 확인한다.

**숫자가 이상하다** → [[03 지표 정의]]와 [[04 알 수 없는 것들]]을 먼저 본다.
스레드 반응이 매주 같은 건 고장이 아니라 API 제약이다.

## 하면 안 되는 것

- 워크플로를 연달아 여러 번 실행하기 (Meta 차단 위험)
- 옛 데이터로 만든 HTML을 저장소에 올리기 (화면 수정은 반드시 `python3 rebuild.py` 로)
- `history.json` / `threads_history.json` 지우기 (과거 기록이 전부 사라짐)
- 토큰을 코드나 문서, 대화창에 적기
