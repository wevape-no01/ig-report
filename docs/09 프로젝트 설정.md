# 09 프로젝트 설정

상위: [[위베이프 SNS 리포트]]

claude.ai에 "위베이프 SNS 리포트" 프로젝트를 만들어 두면, 새 채팅이나 Cowork 작업을
시작할 때 프로젝트만 고르면 됩니다. 파일을 매번 첨부할 필요가 없습니다.

## 만드는 순서

1. claude.ai 왼쪽 **프로젝트** → **새 프로젝트**
2. 이름 `위베이프 SNS 리포트`
3. **지침** 연필 아이콘 → 아래 [[#지침 (그대로 붙여넣기)]] 내용을 붙여넣기
4. **컨텍스트** `+` → **GitHub** → `wevape-no01/ig-report` 저장소 연결
5. **컨텍스트** `+` → **기기에서 업로드** → 이 폴더의 `.md` 노트 전부 올리기
6. (선택) **예정됨** `+` → 매일 아침 사이트 상태 확인 같은 반복 작업

컨텍스트 메뉴에는 **로컬 폴더를 연결하는 항목이 없습니다.** 기기에서 업로드 / 텍스트 내용 추가 /
GitHub / Notion 네 가지뿐입니다. 그래서 노트는 파일로 올려야 합니다.

## 두 가지를 같이 붙이는 이유

| 붙이는 것 | 담기는 내용 | 최신 유지 |
|---|---|---|
| GitHub 저장소 | 코드·데이터·워크플로 | 자동 (커밋하면 반영) |
| 업로드한 `.md` 노트 | 운영 지식·규칙·작업 기록 | 수동 (노트 고치면 다시 올려야 함) |

저장소에는 "왜 이렇게 만들었는지"가 없고, 노트에는 코드가 없습니다. 둘 다 있어야 합니다.

> [!warning] 노트를 고치면 다시 올려야 합니다
> 업로드한 파일은 그 시점의 사본입니다. 옵시디언에서 노트를 고쳐도 프로젝트는 모릅니다.
> 노트를 크게 고친 날에는 프로젝트의 해당 파일을 지우고 다시 올리세요.

## 노트를 고칠 때는 Cowork로

프로젝트에 올린 파일은 **읽기만** 됩니다. 노트를 읽고 고치는 작업은 Cowork 작업을
시작할 때 `ClaudeVault` 폴더를 연결해서 합니다. 프로젝트 설정과는 별개입니다.

## 지침 (그대로 붙여넣기)

```
이 프로젝트는 위베이프(인천 구월동)의 인스타그램·스레드 성과 자동 리포트 사이트를
운영하고 개선하는 작업 공간이다.

사이트 https://wevape-no01.github.io/ig-report/
저장소 https://github.com/wevape-no01/ig-report

[작업 전에]
- 컨텍스트 폴더의 "위베이프 SNS 리포트 / 00 인수인계"를 먼저 읽는다.
- 자세한 내용은 같은 폴더의 01~09 노트에 있다.
- 새 노트를 만들기 전에 관련된 기존 노트가 있는지 먼저 찾아본다.

[절대 규칙]
1. 화면(HTML)을 고쳤으면 build_*.py 를 직접 돌리지 말고 반드시
   `python3 rebuild.py` 로 재생성한다. 옛 데이터로 만든 페이지를 올리면
   사이트가 과거 날짜로 되돌아간다. 2026-08-20과 08-21에 두 번 발생했다.
2. 수집 워크플로를 연달아 실행하지 않는다. 한 번에 Meta API 약 69회 호출이고,
   과거에 개발자 계정이 두 번 차단됐다.
3. 토큰·비밀번호는 코드·문서·대화 어디에도 적지 않는다.
   사용자가 GitHub 또는 Cloudflare 화면에서 직접 입력한다.
4. history.json / threads_history.json 을 지우지 않는다. 과거 비교가 전부 사라진다.
5. 되돌리기 어려운 작업(파일 삭제·덮어쓰기, git 강제 명령)은 실행 전에 반드시 물어본다.

[작업 방식]
- 한국어로 답한다. 결론 먼저, 핵심만. 서론과 마무리 인사는 넣지 않는다.
- UI를 바꿀 때는 예시를 2~3개 만들어 보여주고 고르게 한 뒤 적용한다.
- 색과 글꼴은 layout.py 한 곳에서만 정한다. 페이지마다 따로 정하지 않는다.
- 10개 페이지의 첫 카드 시작 위치(221px)와 본문 폭을 깨는 수정은 하지 않는다.
- 작업이 끝나면 "작업 일지" 폴더에 날짜 노트를 남기고,
  바뀐 내용이 있으면 관련 노트와 "00 인수인계"를 함께 고친다.
- 확실하지 않으면 "확실하지 않음"이라고 밝힌다. 추측을 사실처럼 쓰지 않는다.
```
