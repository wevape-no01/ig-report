# 08 앞으로 할 일

상위: [[위베이프 SNS 리포트]]

## 사이트 비밀번호 걸기 (보류 중)

GitHub Pages로는 안 됩니다([[06 문제 해결 기록]] 마지막 항목).
**Cloudflare Pages로 옮기면** 무료로 비밀번호를 걸 수 있습니다.
`functions/_middleware.js`는 이미 저장소에 넣어 뒀습니다.

남은 절차 (본인이 직접 해야 하는 부분):

1. Cloudflare 가입
2. Pages 프로젝트를 만들고 이 저장소 연결
3. 빌드 설정 — Framework: None / Build command: 비움 / Output: `/`
4. 환경 변수 `SITE_USER`, `SITE_PASS` 입력 (**비밀번호는 Cloudflare 화면에서 직접 입력**)
5. Retry deployment

그 다음 저장소를 비공개로 바꾸고 GitHub Pages를 끄면 완료입니다.
주소가 `*.pages.dev`로 바뀌므로 알림에 들어가는 링크도 함께 고쳐야 합니다.

## 해시태그 수동 점검 (5분 체크리스트)

API로는 안 되니 앱에서 눈으로 봅니다. 대상 태그 5개:
`#전자담배` `#인천전자담배` `#입호흡액상` `#버블몬` `#전담`

각 태그를 검색해 인기 게시물 상위에 어떤 계정·어떤 형식이 올라와 있는지만 봅니다.
숫자를 적을 필요는 없고, **어떤 소재가 상위에 있는지** 감만 잡으면 됩니다.

- 슬랙·디스코드 알림 — `ALERT_WEBHOOK` 시크릿만 넣으면 켜집니다 (`alert.py` 준비됨)
- `test_alert.yml`과 테스트 이슈 #2 — 필요 없어지면 삭제
