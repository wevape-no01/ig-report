# 03 지표 정의

상위: [[위베이프 SNS 리포트]]

## 인스타그램

| 지표 | 뜻 | 주의 |
|---|---|---|
| 도달 | 게시물을 **본 사람 수** (같은 사람이 여러 번 봐도 1명) | 오래된 글일수록 적게 집계됨 |
| 조회수 | 화면에 **표시된 횟수** (같은 사람이 3번 보면 3) | 도달보다 항상 큼 |
| 신규 팔로워 | 그날 늘어난 팔로워 수 | 인스타가 확정해 주는 건 **어제까지** |
| 저장 | 게시물을 저장한 횟수 | 나중에 다시 볼 가치가 있다는 신호 |
| 공유 | 남에게 보낸 횟수 | 새 사람에게 닿는 가장 싼 경로 |
| 반응률 | (좋아요+댓글+저장+공유) ÷ 도달 × 100 | 계정 크기와 무관하게 비교 가능 |

### 신규 팔로워 유입의 두 칸

**어디까지 퍼졌나** — 어제 계정을 본 사람을 팔로워/비팔로워로 나눈 것.
비팔로워 비중이 클수록 새 사람에게 퍼진 것입니다.

**어느 게시물이 데려왔나** — 인스타는 게시물별 팔로우 수를 **평생 누적**으로만 줍니다.
그래서 매일 값을 적어 두고(`follows_log`, 최근 40일) 전날과 빼서 그날치를 만듭니다.
이 계산이 없으면 7월 1일 게시물이 매일 1위로 뜨는 착시가 생깁니다.

## 스레드

스레드에는 **도달이 없습니다.** 조회수(views)만 있습니다.

| 지표 | 뜻 |
|---|---|
| 조회수 | 화면에 표시된 횟수 |
| 반응 | 좋아요 + 답글 + 리포스트 + 인용 + 공유 |
| 반응률 | 반응 ÷ 조회수 × 100 |
| 노출 범위 | 글당 평균 조회수 ÷ 팔로워 수 |

### 누적 반응을 일일 리포트에서 뺀 이유

누적값은 **절대 줄어들지 않습니다.** 콘텐츠를 아무리 못 만들어도 숫자는 올라갑니다.
그래서 "이번 주가 지난주보다 나았나"를 판단할 수 없습니다. 매일 볼 이유가 없는 수치라
2026-08-20에 [콘텐츠 분석] → [세부 분석] 아래쪽으로 옮겼습니다.

쓸모가 아예 없진 않습니다. 제휴 제안이나 광고 단가 협상처럼 **계정 규모를 남에게 보여줄 때**
씁니다. 그리고 반응률을 계산하는 재료이기도 합니다.

## 마케팅에서 실제로 보는 순서

1. **반응률** — 소재의 힘. 계정 크기가 달라도 비교됨
2. **기간별 반응 수** — 늘고 있나 줄고 있나 (스레드는 [[04 알 수 없는 것들]] 참고)
3. **팔로워 증감과 도달·조회수** — 실제 성장

누적 합계는 위 셋 다음입니다.

## 좋아요가 많은 글 ≠ 팔로워를 만드는 글

실제로 확인된 사례입니다. 11월 1일 단일 이미지 게시물은 반응률 순위로는 112위인데,
전체 신규 팔로우 55건 중 22건(40%)을 혼자 만들었습니다.
**반응률과 팔로워 유입은 다른 지표입니다. 둘을 같이 봐야 합니다.**
