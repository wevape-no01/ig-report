# 운영 문서

위베이프 SNS 리포트 사이트의 운영 기록입니다. 코드는 저장소 루트에, "왜 이렇게 만들었는지"는 여기에 있습니다.

원본은 옵시디언 보관함 `ClaudeVault/위베이프 SNS 리포트/` 이고, 이 폴더는 그 사본입니다.
노트를 고쳤으면 이 폴더에도 같은 내용을 커밋해야 프로젝트가 최신 상태를 유지합니다.

## 먼저 읽을 것

- **[00 인수인계](00%20%EC%9D%B8%EC%88%98%EC%9D%B8%EA%B3%84.md)** — 새 대화에서 이어서 작업할 때 이것부터

## 문서

| 파일 | 내용 |
|---|---|
| 01 사이트 구조 | 페이지 구성, 디자인 규칙, 색·글꼴 값 |
| 02 자동 갱신 구조 | 매일 아침 7시에 벌어지는 일, API 제한 |
| 03 지표 정의 | 화면의 숫자가 각각 무슨 뜻인가 |
| 04 알 수 없는 것들 | API가 주지 않아 만들 수 없는 것 |
| 05 알림 시스템 | 종 아이콘·팝업·GitHub 이슈 |
| 06 문제 해결 기록 | 겪은 고장과 원인 |
| 07 운영 체크리스트 | 매일·매주 무엇을 보는가 |
| 08 앞으로 할 일 | 남아 있는 과제 |
| 09 프로젝트 설정 | claude.ai 프로젝트 만드는 법 |
| 작업일지 YYYY-MM-DD | 날짜별 작업 기록 |

## 가장 중요한 규칙

화면(HTML)을 고쳤으면 `build_*.py` 를 직접 돌리지 말고 **`python3 rebuild.py`** 로 재생성합니다.
옛 데이터로 만든 페이지를 올리면 사이트가 과거 날짜로 되돌아갑니다.
