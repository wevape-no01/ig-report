# 10 자동 발행 지침

상위: [[위베이프 SNS 리포트]]

인스타그램·스레드 글을 자동으로 써서 올릴 때 쓰는 규칙입니다.
숫자는 [[03 지표 정의]] 기준이고, 근거는 콘텐츠 분석 페이지의 「진단」과 「다음 4주 실행 지침」에
자동으로 갱신됩니다. **이 노트는 사람이 읽는 요약이고, 실제 값은 화면을 보세요.**

## 왜 이런 규칙인가 (2026-08-22 데이터 기준)

계정: @wevape.no01 · 팔로워 721명 · 분석 게시물 115개 (2025-10-27 ~ 2026-08-07)

| 발견 | 숫자 | 표본 |
|---|---|---|
| 발행이 멈췄다 | 월 19.7개 → 월 2.3개, 신규 팔로우 35건/월 → 합계 1건 | 10개월 |
| 릴스가 더 퍼진다 | 도달 중앙값 378 대 152 (2.5배) | 릴스 10 / 피드 69, 같은 기간 |
| 해시태그는 효과 없다 | 0.78% 대 0.81% | 31 / 27, 같은 기간 |
| 성과가 쏠려 있다 | 상위 21개 글이 신규 팔로워의 62% | 105개 |
| 노출이 사람으로 안 바뀐다 | 도달 100명당 팔로우 0.27건 | 도달 20,664명 |

## 규칙

1. **주 3회** (화·목·토). 품질보다 빈도가 먼저입니다. 이 계정은 2025-12에 월 29개까지 올린 적이 있습니다.
2. **릴스 1 : 피드 2.** 사진 소재도 6~10초 세로 영상으로 감싸면 릴스로 나갑니다.
3. **해시태그는 지역·업종 5개 고정.** 매번 바꾸지 마세요. 그 시간을 발행과 릴스에 쓰세요.
4. **캡션 마지막 3줄 고정** — 무엇을 파는 곳인지 / 어디에 있는지 / 팔로우하면 무엇을 받는지.
5. **게시 시각은 18~20시**를 기본으로. 표본이 충분하지 않아 확정은 아니고, 4주 뒤 다시 잽니다.

## 4주 뒤 판정

| 볼 것 | 지금 → 목표 |
|---|---|
| 발행 수 | 주 3개 |
| 반응률 | 0.83% → 1.00% |
| 도달 100당 팔로우 | 0.27건 → 0.40건 |
| 릴스 | 4주간 4개 |

오르지 않은 규칙은 버리세요. 규칙을 늘리는 것보다 안 되는 규칙을 버리는 게 중요합니다.

## 하면 안 되는 것

> [!danger] 릴스의 팔로우 기여로 판단하지 말 것
> 인스타그램 API 가 릴스에는 팔로우·프로필 방문 수를 주지 않습니다. 0 으로 보이는 건
> 값이 없는 것입니다. 릴스 효과는 **주 단위 계정 전체 팔로워 증감**으로 판단하세요.

> [!warning] 전체 기간 평균으로 A/B 를 판단하지 말 것
> 계정이 활발하던 시기와 식은 시기를 섞으면 가짜 결론이 나옵니다.
> 해시태그가 실제로 그랬습니다. 항상 **같은 기간 안에서** 비교하세요.

## 스레드

스레드는 별도 판단이 필요합니다. 2025-12 이후 올린 글은 조회수는 잡히는데
**좋아요·답글·리포스트가 전부 0** 입니다. 발행이 끊긴 시기와 겹칩니다.
API 문제인지 실제로 반응이 없는 것인지 **확실하지 않습니다** — 스레드 앱에서 최근 글의
좋아요 수를 직접 보면 바로 확인됩니다. 확인 전에는 스레드 수치로 판단하지 마세요.
