# 2026-08-22 작업

상위: [[위베이프 SNS 리포트]]

## UI 통일 — 공통 CSS 한 곳으로

인스타그램과 스레드 일일 리포트의 칸 간격·글꼴·카드 위치가 조금씩 달랐습니다.
원인은 같은 규칙이 `build_dashboard.py` 와 `build_threads.py` 에 **각각 복사**돼 있어서,
고칠 때마다 한쪽만 바뀌며 슬금슬금 벌어진 것이었습니다.
카드 줄 아래 여백 24px/20px, 설명 캡션 11px/11.5px 같은 식이었습니다.

공통 부품(카드·표·그래프·토글)을 `layout.py` 의 **`COMPONENT_CSS`** 한 곳으로 옮기고,
두 빌더는 그 위에 자기 페이지만의 것(계정 탭, 샘플 배너 등)만 더하도록 바꿨습니다.

마지막 1px은 KPI 카드 아래 보조 줄 때문이었습니다. 인스타는 `.delta`(12px),
스레드는 `.note`(11px)로 클래스 이름이 달라 카드 높이가 어긋났고, 그 아래 카드가 통째로
1px씩 밀렸습니다. 두 클래스를 공통 CSS에서 같은 값으로 묶어 해결했습니다.

## 확인한 방식

두 페이지의 **계산된 스타일 15항목**을 브라우저에서 직접 읽어 비교했습니다.
글꼴, 본문 크기, KPI 행 간격·여백, 카드 padding·radius·배경, 라벨/값 글자 크기,
섹션 padding·margin, 섹션 제목·설명, 기간 버튼, 표 글자·머리·칸, 토글, 섹션 간격.

결과: **15/15 전부 동일.** 10개 페이지 전체로도 첫 콘텐츠 y 221px(차이 0),
본문 폭 1265px, 글꼴 1종류로 확인했습니다.

## 새로 정한 규칙

**UI 값은 지시가 있을 때만 바꾼다.** 다른 작업을 하면서 곁다리로 간격이나 글꼴을
조정하지 않습니다. 공통 값은 `COMPONENT_CSS` 한 곳에만 두고, 고친 뒤에는 두 페이지를
재서 같은지 확인합니다. [[01 사이트 구조]] 맨 앞과 [[00 인수인계]] 절대 규칙 4번에 넣었습니다.
