# 2026-08-20 작업

상위: [[위베이프 SNS 리포트]]

## 고친 것

**데이터가 5일째 안 갱신된다는 경고** — 수집은 정상이었고, 디자인 개편 때 옛 데이터로 만든
HTML을 덮어쓴 게 원인이었습니다. 최신 데이터로 10개 페이지를 다시 만들어 올렸습니다.
→ [[06 문제 해결 기록]]

**오늘의 인사이트 칸 강조** — 연노랑 배경 + 왼쪽 노랑 띠, 핵심 문장에 노랑 형광펜.
글자를 13.5px에서 14px로 키우고 줄간격을 넓혔습니다.

**그래프 색** — 검정 일색이던 막대를 연한 베이지로 낮추고 가장 큰 값 하나만 노랑으로.
선 그래프는 아래를 연노랑으로 채우고 마지막 점을 노랑으로.

**신규 팔로워 유입 증감 색** — 인스타·스레드 모두 늘면 초록, 줄면 빨강.

**스레드 날짜별 증감표 삭제** — 바로 아래 팔로워 수 추이 그래프와 중복.

**누적 반응 이동** — 일일 리포트에서 빼고 세부 분석의 참고 지표 위로.
이유는 [[03 지표 정의]].

**알림 세 가지** — 테스트 알림 5개 삭제, 7일 지난 알림은 팝업 제외,
"열어보기" 클릭 시 읽음 처리. 팝업이 페이지마다 다시 뜨던 것도 수정.

**발행 관리 버튼 추가** — 상단 오른쪽, 알림 종 왼쪽. 새 탭으로 열림.
→ https://znsl132-lang.github.io/wevape-web/

**폰·태블릿 메뉴** — 상위 메뉴 세 개가 첫 줄에 남고 하위 메뉴가 아랫줄로.
폰에서 팝업이 메뉴를 가리던 것도 아래쪽으로 옮김.

**폰 가로 밀림** — 최근 게시물 표가 화면을 밀어내던 문제.

**카드 배경** — 콘텐츠 분석 계열 4개 페이지 카드가 투명이라 배경과 섞이던 문제.

**글꼴·위치 통일** — 글꼴 두 종류가 섞여 있던 것을 한 종류로.
페이지 이동 시 좌우로 흔들리던 원인(스크롤바)과 세로 2px 어긋남도 제거.
제목 크기를 24 / 20 / 18 / 14px 네 단계로 정리.

## 확인한 방식

10개 페이지 × 6가지 화면 폭(390·430·768·820·834·1280)에서 자동으로 재서 확인했습니다.
결과: 글꼴 1종류, 첫 카드 시작 위치 전 페이지 221px로 동일(차이 0px),
본문 폭 전 페이지 1265px로 동일.

## 배운 것

- 화면만 고칠 때도 **최신 데이터부터 받아서** 빌드해야 한다
- 스크롤바 유무가 화면 흔들림의 흔한 원인이다
- 공용 스타일은 `layout.py` 한 곳에서만 정해야 어긋나지 않는다
